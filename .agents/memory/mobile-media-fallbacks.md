---
name: Mobile media fallbacks
description: Правило для тяжёлых hero-видео и scroll-driven 3D на мобильных устройствах.
---

Для scroll-driven 3D нужен мгновенно видимый фундамент, который не зависит от WebGL и остаётся до готовности настоящей модели. Один облегчённый GLB можно использовать на мобильных и ПК, если он сохраняет нужный вид дома.

**Why:** При холодном запуске белый экран воспринимается как поломка. Пользователю важнее сразу видеть фундамент и гарантированно дождаться модели, чем сохранять пустой блок без placeholder.

**How to apply:** Рендери лёгкий фундамент в HTML/SVG до загрузки JS/WebGL, скрывай его только после сигнала готовности GLB. Прогревай lazy-код и Draco, не заменяй дом фотографией.
