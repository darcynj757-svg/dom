---
name: Mobile budget network checks
description: Как не сделать headless-проверки lazy-ресурсов непредсказуемо долгими на throttled сети.
---

Большие below-the-fold ресурсы нужно проверять по моменту отправки network request после активации секции, а не по окончанию загрузки ответа.

**Why:** Модель может занимать десятки мегабайт, и на Slow 4G завершение загрузки длится минуты; ожидание response превращает проверку lazy-загрузки в нестабильный долгий тест.

**How to apply:** Сначала зафиксируй отсутствие URL в request-событиях до scroll, затем после scroll ожидай коротким таймаутом появление каждого ожидаемого URL в request-событиях.
