---
name: WebGL preview limits
description: Ограничения автоматического браузера при проверке мобильных Three.js-сцен.
---

Автоматический mobile-браузер может возвращать `false` для WebGL и WebGL2 даже при корректных GLB, Draco и frontend-коде. Такой тест пригоден для проверки поведения без WebGL, но не подтверждает видимость настоящей 3D-сцены на телефоне.

**Why:** В тестовой среде модель и Draco отвечали HTTP 200, но WebGL-контекст был недоступен. Фото вместо настоящей 3D-модели пользователь явно отклонил.

**How to apply:** Настоящую мобильную 3D-сцену подтверждать на WebGL-capable устройстве. Не считать отсутствие Canvas в без-GPU тестовом браузере дефектом ассетов и не заменять модель фотографией без согласования.
