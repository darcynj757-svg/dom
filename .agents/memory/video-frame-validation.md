---
name: Video frame validation
description: Проверка плавности сгенерированных и захваченных видеофайлов.
---

Для scroll-видео нельзя считать ролик плавным только по числу кадров, FPS и длительности. Нужно отдельно проверять последовательность на дубликаты и резкие скачки между соседними кадрами.

**Why:** Захват Canvas или конвертация короткой последовательности может записать сотни кадров с небольшим числом реально изменяющихся состояний. Такой MP4 формально корректен, но визуально дёргается.

**How to apply:** После каждого рендера прогоняй видео через duplicate-frame/scene-change анализ, проверяй первый и последний кадр, а для scroll-связки тестируй `currentTime` от начала до конца. Не принимай файл только по `ffprobe` duration/FPS.
